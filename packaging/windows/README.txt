Yoake (README / お読みください)
==============================

[English]

Yoake is a Rust game client and launcher compatible with Minecraft: Java Edition 26.3.
It works with your existing saves and multiplayer, and lets you prepare the game, manage
instances and install mods from one launcher. Yoake is free and open-source software and does
not bundle any code or assets from the original game.

First run
  1. Open YoakeLauncher.exe.
  2. Sign in with a Microsoft account that owns Minecraft: Java Edition.
  3. Choose a version and install it. The launcher prepares the game files for you.
  4. Press Play.

[日本語]

Yoake は、Minecraft: Java Edition 26.3 と互換性のある Rust 製のゲームクライアント兼ランチャーです。
既存のセーブデータやマルチプレイをそのまま使え、ゲームの準備、インスタンスの管理、Mod の導入を
ひとつのランチャーで行えます。Yoake は無料のオープンソースソフトウェアで、元のゲームのコードや
アセットは含まれていません。

初回起動の手順
  1. YoakeLauncher.exe を開きます。
  2. Minecraft: Java Edition を所有する Microsoft アカウントでサインインします。
  3. バージョンを選んで導入します。ゲームに必要なファイルはランチャーが準備します。
  4. プレイを押します。
