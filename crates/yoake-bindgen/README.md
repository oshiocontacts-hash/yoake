# yoake-bindgen

Generates the engine glue (`yoake_glue/*.rs`), the guest stubs and the reports from rustdoc JSON of the engine
crates; `regen.sh` runs rustdoc and the generator (`regen.sh --check` compares instead of writing).

## `ids.lock.json`

Binding ids are assigned once and never reused or renumbered (`Lock::assign`, `append_only_violations`).

* `reserved` is a list of id ranges the generator **never allocates into**: a new binding gets the next free id after
  `max id + 1`, skipping any reserved range. The list is for modules whose bindings are assigned by hand later
  (`custom_mobs`, 1515..=2514, FR-F4-MOB F4M-0). An entry inside a reserved range is a violation
  (`Lock::reserved_violations`, also part of `append_only_violations`); an `unbound` sentinel entry at the end of
  the range (`custom_mobs::__reserved_range_end`) is allowed and keeps the range visible in the entry list.
* A branch that was cut before a range was reserved may have handed out ids inside it. Merge it by keeping the
  merged lock and renumbering the branch's new bindings after the range (their glue is regenerated by `regen.sh`;
  nothing committed refers to the ids except the generated files).

## Field tables and setters (`--tables`, REM-11)

`yoake-bindgen --config bindgen.json --tables <crate> --tables-dir <dir>` writes one file per module with the
`FieldTable` / `RefFieldTable` statics of every struct that has scalar fields. The stamping overlay includes them
into the module, so private fields are reachable (Forge access-transformer parity).

* Getters exist for every scalar field. A **setter** exists for every scalar field too, except the ones the policy
  refuses (`table_setter_allowed` in `src/lib.rs`):
  * identities and counts the engine keeps consistent: whole snake_case segments `id`, `uuid`, `len`, `length`,
    `index`, `idx`, `seq`, `sequence`, a tuple field `.0` (`forbidden_writable`);
  * derived values and secrets: segments `hash`, `checksum`, `crc`, `generation`, `capacity`, `version`, `nonce`,
    `secret`, `password`, `token`, `salt`, `cipher`, `handle` (`TABLE_INVARIANT_SEGMENTS`);
  * `table_readonly` in `bindgen.json`: `Type.field` or `Type.*` (the struct name or a path suffix). Add an entry
    for a field that carries an invariant the name does not show;
  * every type defined in a file that holds `unsafe` code (`frozen_files`) has no table at all.
  A refused or unknown field index makes `set` return `false`, which a guest sees as `BadField`.
* A shared hook argument (`&T`) has only the `RefFieldTable` (getters), so it can never be written.
* Setters take any bit pattern of the field's type (a float can be set to NaN): the guest owns the consequence, as
  with an access transformer.
* The id lock (`ids.lock.json`) is for the configured targets; table fields are addressed by declaration index and
  have no lock ids, so growing the tables changes no id.
