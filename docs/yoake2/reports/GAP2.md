# GAP2: what Forge/NeoForge/Fabric mods can do that a Yoake 2.0.0 mod cannot yet

Audit date 2026-11-20. Read-only. Engine checkout: `C:\Users\USER\NestgateHorizon\horizon-kit2`, commit `46f5207ff` (2.0.0). All paths below are relative to that checkout. Nothing was built or run; every "can" claim is read from code, WIT, or docs and cited. Where a claim could not be confirmed it says "unverified". No Minecraft source or game files were copied.

Older list re-checked: `reports/S3a.md` (2026-11-12, 28 areas), read from the older worktree only as a checklist.

## Routes and how they are written in the tables

| Tag | Route | What it really is (verified) |
|---|---|---|
| **D** | Data `.yak` `content/` / `.hmod` | JSON + assets in own namespaces, no code. Content kinds are exactly `block, item, mob_effect, creative_tab, entity_type, menu` under `data/<id>/horizon/` (`crates/horizon-mods/src/content.rs:1066-1080`), plus recipes/loot/tags/structures/features/biome modifiers (`docs/mods.md:483-545`). |
| **S** | Sandboxed WASM component | Worlds `client-mod` (19 frozen hooks), `client-full` (208 client hooks + services + GPU), `server-full` (378 server hooks + `server-services`), `inject-mod` (56 value-level mixin sites). `crates/yoake-wasm/wit/coverage.json` (473 catalog hooks), `yoake-full.wit`, `inject-sites.json`. Limits: 64 MiB, no threads, WASI subset with no preopen and no sockets (`crates/yoake-wasm/src/wasi.rs:1-10`). |
| **F** | Full-access core WASM ("Mixin 2") | Core module, imports only `env.{engine_call, engine_take, original, get, set, report, hook_register}` (`crates/yoake-guest-sdk/src/sys.rs:5-14`). Reaches 6 bound engine modules (items, entities, mobs, motion, game_items, entity_query: 755 functions of the 9,265 in `horizon_client`, `docs/yoake2/bindgen/coverage.md:5-12`, `survey-horizon_client.md:5`), and hooks bridged functions of four modules (entities, item_use, mobs, motion: `crates/horizon-client/src/yoake_glue/hook_bridge_*.rs`) plus synthetic SERVER_TICK/CLIENT_TICK/HUD_RENDER. Hook handler sees argument 0 only (`docs/yoake2/HOOK-SLICE-BRIDGE.md:26-28`). |
| **N** | Native DLL (C ABI) | 386-hook catalog (`native-hooks.json`), arbitrary native code. For third parties it is effectively closed: a signed DLL must verify against `YOAKE_COMPILED_PUBLIC_KEYS`, "empty in a build without them" (`crates/horizon-mods/src/yak/installed.rs:7-14`); `docs/native-mods.md:4793-4800` says the production key "is not yet supplied ... signed native loading fails closed"; only `YOAKE_DLL_MODS_UNSIGNED=1` (developer env) loads unsigned bytes. Source-level mixin bundles (`.hnmod`, `docs/mods.md:5-9`) need a rebuilt engine, which the owner rejected as route B (`docs/yoake2/YOAKE_MIXIN2.md:12-15`). So **N does not count as available to third-party mods** in the Status column. |

Distribution note that affects every S row: `wasm_preflight` requires a trusted signature on the installed `.yak` unless the developer switch `YOAKE_WASM_UNSIGNED=1` is on (`crates/horizon-client/src/yak_mods.rs:662-683`). Full-access (F) packages instead need the player's per-hash approval in the launcher (`docs/yoake2/MOD-GUIDE.md:36-60`). Content-only packages without WASM: signature rule unverified.

Status: **same** = a mod author can do essentially what Forge allows. **partial** = a real subset. **missing** = not available to S/F/D mods.

## B. Biggest gaps to close (ranked)

1. **HTTP and sockets for WASM mods.** Every real service mod (leaderboards, Discord bridges, the cooking-duel mod) needs it; the manifest already accepts `service.http` + `[http] hosts` but nothing is wired. Size **M**. Touches `crates/yoake-wasm/src/host_services*`, `crates/horizon-mods/src/yak/http_policy.rs` (policy helper exists), a host thread on `ureq` (already a `horizon-client` dependency), and the WIT `server-services`/`client-services`. No vanilla impact when no mod is installed.
2. **Give full-access mods a host import set** (log, storage, clock, async HTTP, GPU). Today F cannot even log. Size **S-M**. `crates/yoake-guest-sdk/src/sys.rs`, `crates/yoake-slice/src/runtime.rs` (linker), reuse the S services.
3. **Widen F reach beyond four modules.** Block, world, chunk, GUI, render and network code are unbound (755 of 9,265 functions bound); hooks only see argument 0. Size **XL**. `crates/yoake-bindgen`, `crates/yoake-hook-codemod`, `hook-ledger/`, `crates/horizon-client/src/yoake_glue`. **Flag:** every new hook slot on a hot function adds a branch even with no mod; it must stay "one Acquire load" and byte-identical output (benchmark gate).
4. **Let WASM register behaviour objects.** `block-behaviors`, `item-behaviors`, `menu-behaviors`, `capability-providers`, `recipe-types`, `blocks`, `items` are "not applied: holds live engine objects". Size **L**. `crates/horizon-mod-api-gen/src/abi/wasm_adapters.rs`, `crates/horizon-client/src/wasm_mods/full.rs` and `full_adapters.rs`; needs guest-callback behaviour wrappers.
5. **Custom entities with their own model, animation and AI code.** Mob-heavy mods are impossible beyond 8 vanilla templates. Size **XL**. `crates/horizon-mods/src/content.rs` (entity_type), `crates/horizon-client/src/mobs`, `MobType.layers`, OptiFine `.jem` loader (`mobs/cem.rs`) as a base.
6. **Runtime textures usable by blocks, items, entities, particles (dynamic atlas sprites).** Size **M-L**. `crates/horizon-client-render` atlas, `crates/horizon-client/src/game/native_gui_textures.rs`, `wasm_mods/client_services.rs`. Must not change atlas layout when no mod uses it (vanilla output unchanged).
7. **Custom dimensions and travel.** `Dimension` is a three-variant enum; also duplicated in `discord_presence.rs` and `mobs/spawn_rules.rs`. Size **XL**. `crates/horizon-world/src/level/mod.rs`, `worldgen/overrides.rs`, `docs/server-levels.md` machinery, `server_travel.rs`. **Flag:** vanilla level paths and save layout must stay unchanged.
8. **Worldgen from mods: biomes, noise settings, carvers, density functions, biome sources.** Size **L** for data kinds, **XL** for code (custom generators). `crates/horizon-client/src/mod_content.rs:1812-1822` (`WORLDGEN_BUNDLES`), `crates/horizon-world/src/worldgen`. **Flag:** vanilla biomes/terrain must stay byte-for-byte equal with no mod (the loader already promises it for biome modifiers).
9. **IME preedit/composition and a mod text field.** Japanese users cannot type naturally in a mod screen. Size **M**. `crates/horizon-client/src/game/ime.rs`, `crates/horizon-client-render/src/preedit.rs`, new WIT events + a text-field draw command in `yoake-mod.wit` / `yoake-full.wit`.
10. **Threads, async and timers off the hook.** Heavy work and async I/O have no home (20/25 ms hook cap). Size **L** (host worker + message queue, per `YOAKE_MIXIN2.md:123-124`), depends on 1.
11. **Block-entity state write-back and BE read/patch services.** `block_entity_tick`/`menu_button` entity results are dropped; `block-entity-read` / `block-entity-patch-call` have no native service. Size **S-M**. `full_adapters.rs` generator and a native BE service in `horizon-client`.
12. **More data-pack kinds and data-driven enchantments, damage types, game rules, fluids.** Size **M**. `data-pack-files` kinds list (`docs/native-mods.md:1201`), `crates/horizon-mods/src/content.rs:1066-1080` (add `fluid`, `enchantment` kinds).
13. **Non-template blocks and richer state properties (int ranges).** Size **M**. `content.rs` block parsing and `crates/horizon-world` state layout (ids must not move; the 2^20 state cap).
14. **Command argument types and fuller Brigadier.** Size **M**. `native_register_commands` usage parser (`docs/native-mods.md:2208-2214`), `server-full` `register-commands` record.
15. **In-world cancellable pre-key hook, `item_model_select`, `input-key` mapping fix.** Size **S**. `crates/horizon-client/src/wasm_mods/full_adapters.rs` (unsupported entries 1 and 2).

Not in the top 15 but real: data generation tooling (M, `crates/cargo-horizon-mod`), custom criteria/stats registration (M), villager trade-list mutation event (S), mod-to-mod client calls (M), custom SoundInstance behaviours (unverified).

## C. Things Yoake can do that Forge/Fabric cannot (verified)

1. **Per-mod fault isolation.** A trap, fuel/time overrun or 20 bad windows disables only that mod, the engine continues once; Java mods share one JVM fate. `docs/yoake2/MOD-GUIDE.md:~170`, `docs/yoake-wasm-dev.md:462-484`, `crates/yoake-wasm/src/lib.rs:109-120`.
2. **Hot reload of mod code** without restarting the game (sandboxed client modules in dev mode; F via approved-list generation), with a failed new build keeping the old instance. `docs/yoake-wasm-dev.md:121-143`; `docs/yoake2/ENGINE_CALL_ABI.md:281-289`.
3. **Automatic, hash-pinned mod sync on join**, including a restart-and-rejoin flow, host-scoped and removable. `docs/yoake2/JOIN-MODS.md:1-47`.
4. **Content-hash trust for code.** A full-access mod runs only for the exact SHA-256 the player approved; origin (local/catalog/server/friend) is recorded outside the game's reach. `docs/yoake2/MOD-GUIDE.md:36-60`.
5. **Stable ABI across engine rebuilds** (append-only binding ids, versioned `yoake_abi` section), so a built mod keeps working; Forge mods break per Minecraft version. `docs/yoake2/ENGINE_CALL_ABI.md:6-25`; `crates/yoake-bindgen/ids.lock.json`.
6. **A bounded, validated GPU API** (WGSL rewritten with loop guards, per-mod GPU memory caps, device-loss recovery, 576-byte frame ABI) instead of raw GL. `docs/yoake-gpu-coverage.md`.
7. **Host-generated config screens, synced config and permission nodes from a manifest** with no mod code. `docs/yoake-wasm-dev.md:628-725`.
8. **In-engine deterministic mod test driver** (frozen world, real services, multi-client). `docs/yoake-wasm-dev.md:208-428`.
9. **Chained around-hooks with priority** across mods on the same function with a "real original runs at most once" guarantee. `docs/yoake2/ENGINE_CALL_ABI.md` (Hook modes); `docs/yoake2/MOD-GUIDE.md:~120-150`.
10. **Typed streaming PCM audio from a mod** anchored to an entity or position, as a first-class service. `yoake-full.wit:2205-2211`.
