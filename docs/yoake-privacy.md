# Yoake privacy policy

Yoake will not transfer information to other networked systems unless specifically requested by the
user or the person installing or operating it.

What the user asks for, and where it goes:

- **Sign-in** with a Microsoft account uses Microsoft, Xbox Live and Minecraft services to play.
- **Updates**: the launcher reads Yoake's update feed at `portal.yunipop.com` (versions and
  signatures only) and downloads the files the user chooses to install.
- **Yoake portal** sign-in uses an invite code or Discord when the user opens it.
- **Multiplayer** connects to servers, LAN games or friend worlds the user chooses to join.

Yoake builds do not send usage data or crash reports: upstream Horizon telemetry is disabled in the
Yoake brand. Settings, game saves and installed files and caches are stored in the user's local data
folders. Choosing a multiplayer service can transmit game data to that service.

For the Microsoft Store edition, the Microsoft Store manages the package installation and updates
according to its own settings. Microsoft and other services have their own privacy policies.
