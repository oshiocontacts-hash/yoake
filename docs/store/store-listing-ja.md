## アプリ名

Yoake

## 短い説明

Rust 製のゲームクライアントとランチャー。世界の探検、フレンドとのマルチプレイ、MOD をひとつのアプリで楽しめます。

## 説明文

Yoake は、Minecraft: Java Edition 26.3 と互換性を持つ、Rust 製のゲームクライアントとランチャーです。世界の生成やモブ、レッドストーン、コマンド、レシピブックなど、おなじみの遊びを、既存のセーブデータやマルチプレイとともに楽しめます。バニラのセーブデータをそのまま使えるほか、1.8 から 26.2 のワールドは 26.3 へのアップグレードに対応しています。ゲームの準備と更新、インスタンスの管理、MOD の導入を、ひとつのランチャーから行えます。インスタンスごとに遊ぶバージョンや MOD を分けられるので、友だちと遊ぶ環境と、ひとりで遊ぶ環境を気軽に使い分けられます。Windows 向けの Microsoft Store 版では、インストールもアップデートもストアにおまかせです。

通常のプレイには、Minecraft: Java Edition を所有する Microsoft アカウントでのサインインが必要です。既存のゲームインストールを再利用できるほか、インストールがなくても、お持ちのアカウントに対応するゲームファイルを公式の配信元からダウンロードして準備できます。Yoake は無料のオープンソースソフトウェアで、元のゲームのコードやアセットは同梱していません。

本アプリは Minecraft の公式製品ではなく、Microsoft の承認・提携を受けたものではありません。

シングルプレイの世界をそのままフレンドに公開したり、LAN やオンラインサーバーに参加したりできます。フレンドとのプレイでは、ホストが招待コードを発行し、相手がゲームまたはランチャーにコードを入力して参加します。ホストと参加者の間の通信は暗号化されます。ネットワーク環境によっては、ポート転送、VPN、または自分で用意した中継サーバーが必要です。共有を止めるかワールドを閉じると、その招待コードは使えなくなります。

ランチャーのフレンドページでは、フレンドコードによるリクエスト、グループの作成と招待、ブロックを扱えます。Yoake ポータルへのサインインが必要で、ポータル側でまだ有効になっていない間は「まだ使えません」と表示されます。ワールドへの招待コードとは別の仕組みです。フレンドが使えない間も、招待コードや LAN、サーバーでの遊びには影響しません。

MOD は、WebAssembly（Wasm）の .yak パッケージで作るのが基本です。Wasm MOD はゲーム内の隔離環境で動作し、宣言された権限と実行時間・メモリの制限があります。通常の環境でコードを含む MOD を動かすには、Yoake の有効な署名が必要です。署名のない自作 MOD は、開発者向けの設定でのみ試せます。Java 用 MOD の JAR ファイルは動作しません。

MOD 開発には Rust の SDK、サンプル、ホットリロード、ゲームエンジン内でのテストの仕組みを用意しています。画面表示、独自コマンド、設定、データ保存などを組み込めます。選んだ MOD とベースパックは「構成」として保存し、YK1 共有コードで新しいインスタンスとして導入することもできます。利用できる MOD はカタログの掲載内容に依存します。

Modrinth や CurseForge の Modpack は、Yoake が対応できるデータとアセットのコンテンツを取り込めます。リソースパック、データパック、シェーダーパックも利用できます。グラフィックスプリセットや遠方の地形表示、コントローラー対応などの追加設定は、元の見た目を変えるものを既定でオフにして選べます。

ランチャーからサーバーの作成、起動、バックアップ、更新も行えます。インターネット越しのフレンドとは、Tailscale による招待で接続することもできます。ランチャーの表示言語は日本語と英語で、ダーク・ライト・システムに合わせた表示やアクセントカラーを選べます。Microsoft Store 版のランチャーは自己更新せず、パッケージの更新は Microsoft Store が行います。

帽子やペットなどの着せ替え（コスメ）は準備中で、現在は無効です。

互換性は検証済みの範囲に基づくもので、元のゲームとの差異が残っている部分もあります。すべての機能や Java 用 MOD が同じように動作するわけではありません。

## 主な機能

- **Rust 製ゲームクライアント**: 26.3 のワールド、モブ、村人、襲撃、レッドストーン、コマンド、レシピブック、既存のセーブデータに対応。
- **マルチプレイ**: オンラインサーバー、LAN、招待コードによるフレンドワールドへの参加。フレンド間の通信は暗号化。
- **フレンドとグループ**: フレンドコード、リクエスト、グループ招待、ブロック。Yoake ポータルへのサインインが必要で、ポータル側で有効になるまでは利用できません。
- **Wasm MOD と .yak**: 隔離環境で動く Wasm MOD、署名済みカタログ、パッケージの検査、クライアント・サーバー側の MOD に対応。
- **MOD 構成の保存と共有**: ベースパックと MOD を構成として保存し、YK1 コードから新しいインスタンスとして導入。
- **各種パック**: リソースパック、データパック、シェーダーパック、対応できるコンテンツを取り込む Modpack。
- **追加設定**: グラフィックスプリセット、遠方の地形、コントローラー。元の見た目を変えるものは既定でオフ。
- **インスタンスとバージョン管理**: 複数のインスタンス、ゲームの準備、バージョンの選択と更新。
- **サーバー管理**: ランチャーからサーバーを作成・起動し、バックアップや更新を実行。Tailscale での招待にも対応。
- **日本語・英語のランチャー**: ダーク・ライト・システム表示、アクセントカラーを選択可能。

## 新機能

- **Wasm MOD**: Rust から WebAssembly コンポーネントをビルドし、.yak パッケージとして導入可能。クライアント・サーバー側のフック、設定、データ保存、開発用ホットリロード、ゲームエンジン内テストに対応。
- **フレンドとグループ**: フレンドコードとリクエスト、グループの作成・招待、ブロックを追加。ポータル側で有効になっている場合に利用できます。
- **MOD 構成の共有**: MOD とベースパックの組み合わせを YK1 共有コードで共有。
- **ランチャーの新しい見た目**: ダーク・ライト・システム表示とアクセントカラーに対応。

## 年齢区分の質問に答えるためのメモ

- **チャット、フレンド、グループ**: ゲーム内チャットがあります。オンラインサーバー、LAN、フレンドワールドへの参加にも対応します。ランチャーには、フレンドコードによるリクエスト、グループの作成・招待、ブロックの機能があり、利用には Yoake ポータルへのサインインとポータル側での有効化が必要です（未有効の間は「まだ使えません」と表示）。（根拠: `README.md`、`docs/play-with-friends.md`、`launcher/src/friends_view.rs`、`launcher/lang/ja.json`）
- **ユーザーが作ったコンテンツの共有**: MOD は .yak パッケージとして配布・導入でき、MOD とベースパックの構成は YK1 共有コードで他人と共有できます。コスメは現在は既定で無効で（`ON_BY_DEFAULT=false`）、有効になった場合にのみ、装備内容がコスメサービスを通じてほかの対応クライアントに表示されます。ユーザーがコスメを新規投稿する機能は今はなく、予定のみです。（根拠: `docs/api/yoake-mods.md`、`docs/yoake-configs.md`、`docs/cosmetics.md`、`crates/horizon-cosmetics/src/lib.rs`）
- **アプリ内課金**: なし。指定資料にアプリ内課金や有料アイテムの購入機能の記載はなく、コスメ（準備中）のファウンダーセットも無料で、ランダムな抽選はありません。（根拠: `docs/cosmetics.md`、`docs/yoake-store.md`）
- **位置情報・個人情報**: 位置情報を収集する旨の記載はありません。Microsoft アカウントでのサインインには Microsoft、Xbox Live、Minecraft のサービスを使い、Yoake ポータルでは招待コードまたは Discord を使います。マルチプレイでは選択したサーバー等へゲームデータが送られ、接続相手は IP アドレスを認識します。フレンドワールドの招待コードにはホストの LAN・VPN・公開アドレスが含まれ、外部アドレスの確認に使う STUN サーバーはホストの公開 IP アドレスを認識します。（根拠: `docs/yoake-privacy.md`、`docs/play-with-friends.md`）
- **暴力表現**: 元のゲームの内容に準じます。モンスターやほかのモブ、体力や空腹の表現があります。（根拠: `README.md`）

## プライバシーの要点

- **Yoake が送信しないもの**: Yoake ビルドは利用状況データやクラッシュレポートを送信しません。上流のテレメトリー（匿名の「プレイ中」通知を含む）は Yoake ブランドで無効化されています。設定、ワールドのセーブデータ、インストールしたファイルとキャッシュは、ユーザーのローカルデータフォルダーに保存されます。
- **サインイン時の通信**: Microsoft アカウントでサインインすると、プレイに必要な認証のために Microsoft、Xbox Live、Minecraft の各サービスと通信します。Yoake ポータルを開いてサインインする場合は、招待コードまたは Discord を使用します。
- **更新時の通信**: 通常版のランチャーは `portal.yunipop.com` の更新フィードからバージョンと署名の情報を読み、ユーザーが選んだファイルをダウンロードします。Microsoft Store 版では、Microsoft Store がパッケージのインストールと更新をストア自身の設定に従って行います。
- **マルチプレイ時の通信**: ユーザーが参加を選んだサーバー、LAN ゲーム、フレンドワールドと接続し、そのサービスへゲームデータを送信する場合があります。フレンド機能を使う際の通信は、上の年齢区分メモも参照してください。
- **収集を止める方法**: 利用状況データとクラッシュレポートは送信されないため、オフにする操作は不要です。共通ランチャーのコードにある性能統計などの同意画面は、Yoake ブランドでは表示されません。外部サービスとの通信はユーザーの操作を起点とするため、サインイン、ポータル、マルチプレイなどを利用しなければ、その通信を行いません。Store 版の更新は Microsoft Store の設定で管理します。
